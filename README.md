# Learner Coder

Free code learning app.

**Live:** https://learner-coder.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `learner-coder`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
pnpm test
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
